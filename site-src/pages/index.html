[[i:sparkles]]Introduction

Ask your Primavera P6 schedule, in plain language

MCP for Primavera P6 is a local MCP server for Claude, ChatGPT, Cursor and VS Code. It reads the P6 Professional database or XER files and computes the answer from the schedule: driving path, total float, the DCMA 14-point check, what changed since the last update, what-if and risk. When you allow it, it edits the schedule too: previewed, confirmed by you, backed up and logged.

[[i:link]]Skills: one request, one fixed report

A P6 skill is a SKILL.md that tells the AI which tools to call, in which order, and which field fills each figure of the report. The figures are copied from the schedule, never computed by the model. Clients use a skill when your request matches its description; Claude Code also runs it as /p6-<name>.

Driving path and what-if, recorded

A 30 second replay of a real run: the assistant traces the driving path of MS-1100 - Project completion, then tests a change on PRC-TR-1040 - Power transformers 225/63 kV - manufacturing.

Transcript of the recording

You: What drives MS-1100 - Project completion in DEMO-SS225?

Tools: p6_driving_path(project="DEMO-SS225", target="MS-1100") returns 24 activities, root PRC-TR-1040 - Power transformers 225/63 kV - manufacturing at the data date. p6_float_origin(project="DEMO-SS225", task_code="MS-1100"): the float comes from the project must finish by date, 16 Aug 2027.

Assistant: MS-1100 - Project completion is forecast for 5 Oct 2027. Its driving path has 24 activities and starts at the data date with PRC-TR-1040 - Power transformers 225/63 kV - manufacturing, still in progress, then the factory test, delivery, installation of TR1 and TR2, tests and energization. Total float is -36 days: the project must finish by 16 Aug 2027.

You: What if PRC-TR-1040 - Power transformers 225/63 kV - manufacturing finishes 15 working days earlier?

Tool: p6_schedule_whatif(project="DEMO-SS225", edits=[{"op": "duration", "task_code": "PRC-TR-1040", "add_remaining_days": -15}]), in memory: finish 14 Sep 2027, 15 working days earlier.

Assistant: Nothing is written: in memory, the finish moves from 5 Oct to 14 Sep 2027, 15 working days (21 calendar days) earlier. Total float on the path improves from -36 to -21 days, and 27 activities move. The engine matches P6's last F9 on 100 % of the open activities.

    P6MCP-Setup-2.0.0.exe from the latest release; check it against SHA256SUMS.txt.

    Restart your MCP client and ask: "List my P6 projects".

[[i:link]]FAQ

What is an MCP server for Primavera P6?

MCP (Model Context Protocol) is the open standard AI assistants use to call tools. This server gives an assistant 58 tools that read and analyse P6 schedules, so you ask in plain language and get answers computed from the schedule rather than guessed by the model.

Can the AI change my P6 schedule?

Only if you allow it. Writes are off by default. When on, each change is previewed in a dry run and applied only with a single-use token after your explicit yes, a backup is taken first, and P6 must be closed. Planned dates and float are never written: P6 computes them when you press F9.

Does my schedule leave my PC?

The server runs locally and sends nothing anywhere. What the tools return goes to the AI model of your MCP client; with a cloud model that means its provider. For confidential projects use a local model, for example in LM Studio.

Are the dates computed by the AI?

No. Dates and float come from P6's last schedule run. What-if and risk use the server's CPM engine, and p6_cpm_validate shows how closely it matches P6's own dates on your project before you rely on it.

Which P6 versions and databases are supported?

P6 Professional standalone (SQLite), tested with version 25.12; other versions are read only until tested or trusted. XER files work without P6. P6 EPPM and P6 Professional on SQL Server or Oracle are not supported.

Do I need P6 installed?

Not for XER files: XER-only mode analyses them without P6 or a P6 database.

Does it work with ChatGPT?

Through Codex, which starts local MCP servers, or through OpenAI's Secure MCP Tunnel for ChatGPT chat. Both routes are documented in the README but not yet tested by the maintainer. Claude Desktop, Claude Code, Cursor, VS Code, LM Studio and Cline are registered by the installer.

Does it run on macOS or Linux?

No. P6 Professional is a Windows program and the server is built for Windows 10 and 11.
