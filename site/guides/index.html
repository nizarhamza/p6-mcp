Primavera P6 with an AI assistant: guides

Each guide gives the prompts to type, the tools the assistant calls and real results from the public demo project DEMO-SS225, a 225/63 kV substation schedule with synthetic data.

  • DCMA 14-point check with AI

    Run the 14 checks with the thresholds set in P6, read each failed check, drill into the activities behind it and follow the trend between updates.

    Read the guide

  • Driving path in P6 with Claude

    Trace what drives an activity back to its root cause, see where its total float comes from, then test a change in memory.

    Read the guide

  • Comparing two P6 updates with AI

    Activities and links compared one by one, slip causes, float erosion, and the integrity flags that explain a finish date that moved.

    Read the guide

  • AI review of an XER before submission

    File checks, logic, progress and integrity of an update XER, without importing it, before it goes to the client or after it arrives.

    Read the guide
