Ask your Primavera P6 schedule, in plain language

A local Primavera P6 MCP server for Claude, ChatGPT, Cursor and VS Code. It reads the P6 Professional database or XER files and computes the answer from the schedule: driving path, total float, the DCMA 14-point check, what changed since the last update, what-if. When you allow it, it edits the schedule too: previewed, confirmed by you, backed up and logged.

Questions a scheduler asks, answered from the schedule

The server does the scheduling arithmetic on P6's own data; the model only explains the result. Dates and float come from the last schedule run (F9).

What drives the finish date?
p6_driving_path follows the driving predecessors back to the root cause (a constraint, the data date, an actual date); p6_float_origin says where the total float comes from.
Does this schedule pass the DCMA 14-point check?
p6_health_check runs the 14 checks with the thresholds set in P6 for the project, the critical path test, CPLI and BEI, and lists the activities behind every failed check. DCMA guide
What changed since last month's update?
p6_compare_projects compares activity by activity and link by link, with slip causes and float erosion; p6_update_integrity lists the changes a reviewer should question. Comparison guide
What if procurement takes four more weeks?
p6_schedule_whatif applies the change in memory and runs a CPM engine checked against P6's own dates (p6_cpm_validate); nothing is written.
How likely is the contract finish?
p6_schedule_risk runs a Monte Carlo simulation on the remaining durations: P50 and P80 finish, on-time probability, criticality index.
What is coming up in the next two weeks?
p6_lookahead lists what starts, finishes or runs in the window, critical work first; p6_milestones sets each milestone against its baseline date.
Is this XER ready to submit?
p6_inspect_xer runs the import pre-flight checks without importing; XER-only mode then runs every analysis on the file alone. XER review guide

All 58 tools, with what each one reads or writes

Edits go through the steps you would take yourself

XER-only MCP servers stop at reading a file, or rewrite an XER you import again. This one writes to the P6 Professional database: durations, logic, constraints, actual dates, units, UDFs. The server enforces this sequence on every call.

  1. Off until you turn it on

    Writes need the Full tool profile and "Allow write operations" in the Settings window.

  2. Dry run first

    The tool returns the plan of every change and a single-use confirmation token. Deletes and restores also need a typed confirmation.

  3. Your explicit yes, with P6 closed

    The write is refused while PM.exe runs, on an untested P6 schema, or if the database changed since the dry run.

  4. Backup, then one transaction

    A copy of the database is taken before the change; a batch of edits succeeds or fails as a whole.

  5. Edit log

    Every confirmed write is recorded with its before and after values. Any backup can be restored.

  6. F9 in P6

    Planned, early and late dates and float are never written: open P6 and schedule.

What it does not do

  • No P6 EPPM, no P6 on SQL Server or Oracle: P6 Professional standalone (SQLite) and XER files only.
  • Windows only, like P6 Professional.
  • No new activities except through an XER import.
  • No cloud service and no telemetry. What the tools return goes to the model your MCP client uses: pick a local model for confidential schedules.

Install in five minutes

  1. Download P6MCP-Setup-2.0.0.exe from the latest release and check it against SHA256SUMS.txt.
  2. Run it: per-user install, no administrator rights. On its last page it offers to register the server with the MCP clients it finds.
  3. In the Settings window, pick your P6 database, click Test connection (read only), then Use this database and Save.
  4. Restart your MCP client and ask: "List my P6 projects".

FAQ

What is an MCP server for Primavera P6?

MCP (Model Context Protocol) is the open standard AI assistants use to call tools. This server gives an assistant 58 tools that read and analyse P6 schedules, so you ask in plain language and get answers computed from the schedule rather than guessed by the model.

Can the AI change my P6 schedule?

Only if you allow it. Writes are off by default. When on, each change is previewed in a dry run and applied only with a single-use token after your explicit yes, a backup is taken first, and P6 must be closed. Planned dates and float are never written: P6 computes them when you press F9.

Does my schedule leave my PC?

The server runs locally and sends nothing anywhere. What the tools return goes to the AI model of your MCP client; with a cloud model that means its provider. For confidential projects use a local model, for example in LM Studio.

Which P6 versions and databases are supported?

P6 Professional standalone (SQLite), tested with version 25.12; other versions are read only until tested or trusted. XER files work without P6. P6 EPPM and P6 Professional on SQL Server or Oracle are not supported.

Does it work with ChatGPT?

Through Codex, which starts local MCP servers, or through OpenAI's Secure MCP Tunnel for ChatGPT chat. Both routes are documented in the README but not yet tested by the maintainer. Claude Desktop, Claude Code, Cursor, VS Code, LM Studio and Cline are registered by the installer.

Does it run on macOS or Linux?

No. P6 Professional is a Windows program and the server is built for Windows 10 and 11.
