Introduction

Ask your Primavera P6 schedule, in plain language

MCP for Primavera P6 is a local MCP server for Claude, ChatGPT, Cursor and VS Code. It reads the P6 Professional database or XER files and computes the answer from the schedule: driving path, total float, the DCMA 14-point check, what changed since the last update, what-if and risk. When you allow it, it edits the schedule too: previewed, confirmed by you, backed up and logged.

Download for WindowsVersion 2.0.0 installer, Windows 10 and 11 See how it works
  • Free, Apache 2.0
  • Runs on your PC, no telemetry
  • Writes off until you allow them
  • Not affiliated with Oracle

What it answers

The questions a scheduler asks on every update. The server does the scheduling arithmetic on P6's own data; the model only explains the result. Dates and float come from the last schedule run (F9).

  • What drives the finish date?

    The chain of driving predecessors back to its root cause (a constraint, the data date, an actual date), and where the total float comes from.

    p6_driving_pathp6_float_originDriving path guide

  • Does it pass the DCMA 14-point check?

    The 14 checks with the thresholds set in P6 for the project, the critical path test, CPLI and BEI, and the activities behind every failed check.

    p6_health_checkDCMA guide

  • What changed since the last update?

    Activity by activity and link by link: slips and their causes, float erosion, and the changes a reviewer should question.

    p6_compare_projectsp6_update_integrityComparison guide

  • What if procurement takes four more weeks?

    The change is applied in memory and run through a CPM engine checked against P6's own dates. Nothing is written.

    p6_schedule_whatifp6_cpm_validate

  • How likely is the contract finish?

    Monte Carlo on the remaining durations: P50 and P80 finish dates, the chance of finishing on time, how often each activity is critical.

    p6_schedule_risk

  • What is coming up in the next weeks?

    What starts, finishes or runs in the window, critical work first, and each milestone against its baseline date.

    p6_lookaheadp6_milestones

  • How far along are we?

    Percent complete by units, physical and duration, earned value and SPI at the data date, and the S-curve against the baseline.

    p6_project_summaryp6_progress_curve

  • Is this XER ready to submit?

    The import pre-flight checks without importing, then every analysis on the file alone in XER-only mode.

    p6_inspect_xerXER review guide

Skills: one request, one fixed report

A P6 skill is a SKILL.md that tells the AI which tools to call, in which order, and which field fills each figure of the report. The figures are copied from the schedule, never computed by the model. Clients use a skill when your request matches its description; Claude Code also runs it as /p6-<name>.

The 15 core skills

Installed by the app at its first start and kept up to date from the skill shop. Three of them use write tools and are offered only when writes are allowed.

  • Weekly update review

    Progress, finish, critical path, slippage, changes since the last update, look-ahead and actions.

    Tools it calls: p6_project_summary, p6_progress_check, p6_critical_path, p6_lookahead, p6_compare_projects

  • Schedule quality audit

    DCMA 14 score and grade, engine check, trend, dangling ends, redundant links; fixes proposed only.

    Uses write tools

    Tools it calls: p6_cpm_validate, p6_health_check, p6_health_check_compare, p6_dangling, p6_redundant_links, p6_float_analysis, p6_float_origin

  • Update import (safe)

    Inspect an update XER, dry run the import, report what it would change, apply on your yes.

    Uses write tools

    Tools it calls: p6_inspect_xer, p6_import_xer

  • Delay what-if

    Delay one activity in memory: what drives it, then the new finish, milestones and critical counts.

    Uses write tools

    Tools it calls: p6_get_activity, p6_driving_path, p6_float_origin, p6_schedule_whatif

  • Baseline variance

    Finish variance, slip causes, the activities that moved most, logic changes and earned value.

    Tools it calls: p6_project_summary, p6_compare_projects, p6_progress_curve

  • Excel dashboard

    The Excel dashboard, then a short summary of its cards, failed DCMA checks and warnings.

    Tools it calls: p6_project_summary, p6_export_dashboard

  • List projects by EPS

    The projects of the database grouped by EPS, with status, data date and finish.

    Tools it calls: p6_list_eps, p6_list_projects

  • Look-ahead brief

    What runs, starts and finishes in the next weeks, critical work first, week by week.

    Tools it calls: p6_lookahead

  • Progress and earned value

    Percent complete by every method, earned value and SPI, the S-curve against the baseline.

    Tools it calls: p6_project_summary, p6_progress_curve, p6_list_wbs

  • Float and near-critical

    Float statistics and ranges, the float paths of the last F9, near-critical activities.

    Tools it calls: p6_float_analysis, p6_float_paths, p6_critical_path

  • Milestone tracker

    Milestones against the baseline, the most late ones and what drives the first of them.

    Tools it calls: p6_milestones, p6_driving_path

  • Resource and WBS summary

    Units and costs by resource, then activities and units by WBS and by status.

    Tools it calls: p6_resource_summary, p6_group_summary

  • Update integrity audit

    Changes in an update that a reviewer should question, against the previous update.

    Tools it calls: p6_update_integrity, p6_compare_projects

  • Schedule risk (Monte Carlo)

    Monte Carlo on the CPM engine: P50 and P80 finish, chance to finish on time, criticality.

    Tools it calls: p6_cpm_validate, p6_schedule_risk

  • Logic and date integrity

    Do the stored dates follow from the logic? The CPM engine against the last F9.

    Tools it calls: p6_cpm_validate, p6_schedule_options

Driving path and what-if, recorded

A 30 second replay of a real run: the assistant traces the driving path of MS-1100 - Project completion, then tests a change on PRC-TR-1040 - Power transformers 225/63 kV - manufacturing.

Transcript of the recording

You: What drives MS-1100 - Project completion in DEMO-SS225?

Tools: p6_driving_path(project="DEMO-SS225", target="MS-1100") returns 24 activities, root PRC-TR-1040 - Power transformers 225/63 kV - manufacturing at the data date. p6_float_origin(project="DEMO-SS225", task_code="MS-1100"): the float comes from the project must finish by date, 16 Aug 2027.

Assistant: MS-1100 - Project completion is forecast for 5 Oct 2027. Its driving path has 24 activities and starts at the data date with PRC-TR-1040 - Power transformers 225/63 kV - manufacturing, still in progress, then the factory test, delivery, installation of TR1 and TR2, tests and energization. Total float is -36 days: the project must finish by 16 Aug 2027.

You: What if PRC-TR-1040 - Power transformers 225/63 kV - manufacturing finishes 15 working days earlier?

Tool: p6_schedule_whatif(project="DEMO-SS225", edits=[{"op": "duration", "task_code": "PRC-TR-1040", "add_remaining_days": -15}]), in memory: finish 14 Sep 2027, 15 working days earlier.

Assistant: Nothing is written: in memory, the finish moves from 5 Oct to 14 Sep 2027, 15 working days (21 calendar days) earlier. Total float on the path improves from -36 to -21 days, and 27 activities move. The engine matches P6's last F9 on 100 % of the open activities.

The Settings app

Installed with the server, it holds every setting the server reads: the database, the MCP clients, the tool profile and the write switch, the instructions every client receives, the skills and the shop. It follows the Windows light or dark mode, like these captures follow this page's theme.

Safe writes

XER-file servers read a file, and some edit an XER that you import again. This one writes to the P6 Professional database itself: durations, logic, constraints, actual dates, units, UDFs. The server enforces this sequence on every call, whatever the client.

Then press F9 in P6

Planned, early and late dates and float are never written: the server updates the audit fields the way P6 does, and P6 computes the dates when you schedule.

What is in the repository

Two public repositories: the server and app, and the skill catalog. Everything you install is built from them by GitHub Actions.

Install in five minutes

Windows 10 or 11, next to P6 Professional. Python is bundled: nothing else to install.

  1. Download

    P6MCP-Setup-2.0.0.exe from the latest release; check it against SHA256SUMS.txt.

  2. Run the installer

    Per-user install, no administrator rights. Its last page offers to register the server with the MCP clients it finds.

  3. Pick your database

    In the Settings window: your P6 database, Test connection (read only), Use this database, Save.

  4. Ask

    Restart your MCP client and ask: "List my P6 projects".

FAQ

What is an MCP server for Primavera P6?

MCP (Model Context Protocol) is the open standard AI assistants use to call tools. This server gives an assistant 58 tools that read and analyse P6 schedules, so you ask in plain language and get answers computed from the schedule rather than guessed by the model.

Can the AI change my P6 schedule?

Only if you allow it. Writes are off by default. When on, each change is previewed in a dry run and applied only with a single-use token after your explicit yes, a backup is taken first, and P6 must be closed. Planned dates and float are never written: P6 computes them when you press F9.

Does my schedule leave my PC?

The server runs locally and sends nothing anywhere. What the tools return goes to the AI model of your MCP client; with a cloud model that means its provider. For confidential projects use a local model, for example in LM Studio.

Are the dates computed by the AI?

No. Dates and float come from P6's last schedule run. What-if and risk use the server's CPM engine, and p6_cpm_validate shows how closely it matches P6's own dates on your project before you rely on it.

Which P6 versions and databases are supported?

P6 Professional standalone (SQLite), tested with version 25.12; other versions are read only until tested or trusted. XER files work without P6. P6 EPPM and P6 Professional on SQL Server or Oracle are not supported.

Do I need P6 installed?

Not for XER files: XER-only mode analyses them without P6 or a P6 database.

Does it work with ChatGPT?

Through Codex, which starts local MCP servers, or through OpenAI's Secure MCP Tunnel for ChatGPT chat. Both routes are documented in the README but not yet tested by the maintainer. Claude Desktop, Claude Code, Cursor, VS Code, LM Studio and Cline are registered by the installer.

Does it run on macOS or Linux?

No. P6 Professional is a Windows program and the server is built for Windows 10 and 11.
